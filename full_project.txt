# Dataset Card: CloudSEN12+ L1C Binary Cloud-Screening Subset (`cloud_export_v2`)

## 1. Source, Version, and License
- **Dataset:** CloudSEN12+ (v1.1.2, Level-1C Top-of-Atmosphere reflectance), accessed via `tacoreader` (`tacofoundation:cloudsen12-l1c` / Hugging Face `tacofoundation/cloudsen12`).
- **License:** CC0 1.0 Universal (Public Domain), per the dataset documentation.
- **Citations:**
  - Aybar, C. et al. (2022). *CloudSEN12, a global dataset for semantic understanding of cloud and cloud shadow in Sentinel-2*. Scientific Data, 9(1), 782.
  - Aybar, C. et al. (2024). *CloudSEN12+: The largest dataset of expert-labeled pixels for cloud and cloud shadow detection in Sentinel-2*. Data in Brief.

## 2. Selection Rule, Split Method & Leakage Check
- **Selection Rule:** Filtered strictly to high-quality expert-labeled patches (`label_type == 'high'`) with native projection size $509 \times 509$ (`real_proj_shape == 509`), yielding 10,000 total patches (`results/manifest_all.csv`, excluding 847 high-quality $2000 \times 2000$ patches and all scribble/unlabeled patches).
- **Split Method & Leakage Check:** Official `tortilla:data_split` scene-level assignment grouped by `roi_id`. Verified that no `roi_id` appears in more than one split via `assert (man.groupby('roi_id')['split'].nunique() == 1).all()`.
- **Exported Counts & Class Balance (`results/manifest_export.csv`):**
  - **Train:** 4,000 patches (stratified subsample across 10% cloud-cover deciles with `random_state=42` from the 8,490 official train patches; binary cloudy fraction = `0.207250`, vs. `0.207303` across all 8,490 train patches).
  - **Validation:** 535 patches (100% of official validation split; binary cloudy fraction = `0.218692`).
  - **Test:** 975 patches (100% of official test split; binary cloudy fraction = `0.204103`).

## 3. Labeling Rule & Mask Alignment Verification
- **Cloud Fraction:** `cloud_pct = thick_percentage + thin_percentage`.
- **Position-Indexed Mask Verification (`cloud_export_v2`):** Each patch is read by its 0-based `tacoreader` table position (`pos`) and checked against its cropped $509 \times 509$ pixel-level semantic mask (`classes 1 + 2`). Across all 5,510 exported patches, the absolute difference between mask-derived cloud percentage and metadata `cloud_pct` is verified to be $\le 3.0\%$ (`train`: mean diff `0.24%`, max `1.92%`; `validation`: mean diff `0.24%`, max `1.33%`; `test`: mean diff `0.26%`, max `2.61%`).
- **Binary Target (`label`):**
  - `1` (**Cloudy / Discard candidate**): `cloud_pct >= 70.0%` ($T = 70\%$ pre-registered prior to training).
  - `0` (**Keep-worthy tile**): `cloud_pct < 70.0%` (trained on all patches without dropping intermediate cloud bands).
- **Cloud Shadow Handling:** `cloud_shadow_percentage` counts as ground (`0`), not cloud, and is retained in `results/manifest_export.csv` for downstream error analysis.
- **Imbalance Policy:** No resampling or class weights applied during baseline training so predicted probabilities remain calibrated for asymmetric threshold ($\tau$) selection.

## 4. Preprocessing & Normalization Statistics
1. **Bands:** Sentinel-2 L1C RGB bands `B04` (Red), `B03` (Green), `B02` (Blue), corresponding to 1-indexed `rasterio` channels `[4, 3, 2]`.
2. **Padding Crop:** Cropped the 3-pixel zero-padding strip along the bottom and right edges (`img[:, :509, :509]`).
3. **Whole-Patch Resize:** Resized full $509 \times 509$ patches to $224 \times 224$ via area interpolation (`cv2.INTER_AREA`) and stored as `int16` digital numbers (`1,659,081,360` bytes / ~1.66 GB across 12 `.npz` shards). Whole-patch resizing preserves alignment with the whole-patch `cloud_pct` label.
4. **Reflectance Scaling & Standardization:** The ESA `-1000` radiometric offset is already harmonized in CloudSEN12+ L1C patches (`min > 0`). Values are divided by `10,000.0`, clamped to `[0.0, 1.0]`, and standardized using training-split-only statistics (`results/norm_stats.json`, computed on `train_X.npy[::10]`):
   - **Per-channel Mean (R, G, B):** `[0.219371, 0.213987, 0.229659]`
   - **Per-channel Std (R, G, B):** `[0.208468, 0.186713, 0.197026]`
5. **Training Augmentations:** Random horizontal flip ($p = 0.5$), random vertical flip ($p = 0.5$), and random $90^\circ$ rotations ($k \in \{0, 1, 2, 3\}$). No color jitter or brightness changes are applied.

## 5. Known Biases & Limitations
- **Curated Cloud-Cover Distribution:** CloudSEN12+ was sampled to span all cloud fractions (~25% spike near 0% and uniform spread across 10–100%), so raw discard rates on this dataset do not represent natural orbital cloud encounter frequencies without reweighting.
- **Spectral & Spatial Scope:** Uses 3-band RGB thumbnails ($224 \times 224$) from Sentinel-2 L1C TOA reflectance (excluding SWIR/cirrus bands `B10`/`B11`), serving as a proxy for a low-cost RGB cubesat imager rather than a full 13-band multispectral payload.

import os
import json
import pandas as pd 
import torch
import numpy as np

def load_norm_stats(path="results/norm_stats.json"):
    with open(path, "r") as f:
        d = json.load(f)
    return d["mean"], d["std"]

class CloudDS(torch.utils.data.Dataset):
    def __init__(self, split, mean=None, std=None, train=False, root="data/processed", stats_path="results/norm_stats.json"):
        if mean is None or std is None:
            mean, std = load_norm_stats(stats_path)
        self.x = np.load(f"{root}/{split}_X.npy", mmap_mode="r")
        self.y = np.load(f"{root}/{split}_y.npy")
        self.mean = torch.tensor(mean, dtype=torch.float32).view(3, 1, 1)
        self.std = torch.tensor(std, dtype=torch.float32).view(3, 1, 1)
        self.train = train

    def __len__(self):
        return len(self.y)

    def __getitem__(self, i):
        x = torch.from_numpy(self.x[i].astype(np.float32)) / 10000.0
        x = x.clamp(0.0, 1.0)
        if self.train:
            if torch.rand(1) < 0.5:
                x = torch.flip(x, dims=[2])
            if torch.rand(1) < 0.5:
                x = torch.flip(x, dims=[1])
            x = torch.rot90(x, int(torch.randint(0, 4, (1,))), dims=[1, 2])
        return (x - self.mean) / self.std, int(self.y[i])

def save_stratified_grid(dataset, manifest_split_df, out_path, title, seed=42):
    mean, std = load_norm_stats()
    mean_t = torch.tensor(mean).view(3, 1, 1)
    std_t = torch.tensor(std).view(3, 1, 1)

    rng = np.random.default_rng(seed)
    idx_0 = np.where(manifest_split_df["label"].to_numpy() == 0)[0]
    idx_1 = np.where(manifest_split_df["label"].to_numpy() == 1)[0]
    pick_0 = rng.choice(idx_0, size=13, replace=False)
    pick_1 = rng.choice(idx_1, size=12, replace=False)
    picks = np.concatenate([pick_1, pick_0])  # Top 12 are y=1, bottom 13 are y=0

    fig, axes = plt.subplots(5, 5, figsize=(12, 12))
    for ax, i in zip(axes.flat, picks):
        x_norm, y = dataset[int(i)]
        rgb = (x_norm * std_t + mean_t).clamp(0.0, 1.0).permute(1, 2, 0).numpy()
        rgb_vis = np.clip(rgb * 2.5, 0.0, 1.0)  # 2.5x display gain for dark TOA reflectance
        cloud_pct = manifest_split_df.iloc[int(i)]["cloud_pct"]
        ax.imshow(rgb_vis)
        ax.set_title(f"idx={int(i)} | y={y} ({cloud_pct:.0f}%)", fontsize=8.5)
        ax.axis("off")

    plt.suptitle(f"{title}\n(Stratified sample: 12 y=1, 13 y=0 | Display brightened x2.5)", fontsize=12)
    plt.tight_layout()
    plt.savefig(out_path, dpi=150)
    plt.close()
    print(f"Saved stratified visual grid: {out_path}")

# src/merge_shards.py
import glob
import json
import numpy as np
import pandas as pd

export_df = pd.read_csv("results/manifest_export.csv")
updated_splits = []

for split in ["test", "validation", "train"]:
    files = sorted(glob.glob(f"data/processed/shards/{split}_*.npz"))
    assert len(files) > 0, f"No shards found for {split} in data/processed/shards/"
    parts = [np.load(f) for f in files]

    X = np.concatenate([p["X"] for p in parts], axis=0)
    y = np.concatenate([p["y"] for p in parts], axis=0).astype(np.int64)
    idx = np.concatenate([p["idx"] for p in parts], axis=0)

    sub_df = export_df[export_df["split"] == split].reset_index(drop=True).copy()
    assert len(X) == len(sub_df), f"Length mismatch in {split}: {len(X)} vs {len(sub_df)}"
    assert X.shape[1:] == (3, 224, 224) and X.dtype == np.int16, f"Unexpected shape/dtype: {X.shape}, {X.dtype}"
    assert np.array_equal(idx, sub_df["idx"].to_numpy()), f"idx alignment mismatch in {split}!"
    assert np.array_equal(y, sub_df["label"].to_numpy()), f"label alignment mismatch in {split}!"

    # Verify v2 position and mask_cloud_pct fields
    if "pos" in parts[0] and "mask_cloud_pct" in parts[0]:
        pos = np.concatenate([p["pos"] for p in parts], axis=0)
        mask_pct = np.concatenate([p["mask_cloud_pct"] for p in parts], axis=0)
        sub_df["pos"] = pos
        sub_df["mask_cloud_pct"] = np.round(mask_pct, 4)
        abs_diff = np.abs(mask_pct - sub_df["cloud_pct"].to_numpy())
        assert abs_diff.max() <= 3.0, f"Mask diff > 3% in {split}: {abs_diff.max():.2f}%"
        diff_str = f"mean_diff={abs_diff.mean():.2f}%, max_diff={abs_diff.max():.2f}%"
    else:
        diff_str = "WARNING: v1 shard detected (no mask_cloud_pct field)"

    updated_splits.append(sub_df)
    np.save(f"data/processed/{split}_X.npy", X)
    np.save(f"data/processed/{split}_y.npy", y)
    print(f"{split:10s} | shape: {str(X.shape):18s} | cloudy: {y.mean():.6f} | {diff_str}")

# Save manifest_export.csv with verified pos and mask_cloud_pct columns
pd.concat(updated_splits, ignore_index=True).to_csv("results/manifest_export.csv", index=False)
